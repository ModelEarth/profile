# Info page: state models and the energy view

Plan for [localsite/info](../../localsite/info/) so the charts use the state's own USEEIO model when a state is in the hash, plus a new energy view for states built from EPA eGRID data.

## Goals

1. National view (no state): the USEEIO national model, USEEIOv2.0.1-411, with 23 indicators.
2. State view (`state=AL`): that state's model, ALEEIOv1.0-s-20, with 16 indicators. It has no ENRG, NNRG, RNRG, MNRL, PEST, CCDD or CMSW. No `beta=true` needed.
3. The existing visualizations work with either indicator list. These are the heatmap mosaic (Impact Levels), the inflow-outflow grid, the indicator dropdown and the industry detail impact bars.
4. `set=energy` with a state: hide the USEEIO charts that have no energy indicators. Show a state electricity view and table from eGRID 2024 instead. Optimize for mobile.
5. `set=energy` with no state: keep the USEEIO national charts, which have the energy indicators, and add the eGRID view for all states.

It uses only the standard library. Run it from the webroot with `python3 useeio-json/egrid/egrid_to_js.py`.

## Notes on the useeio_widgets bundle (io/build/lib/useeio_widgets.js)

These are handled in `applyIO()` in naics.js, without editing the built bundle:

- **CORS:** every request sets a `Content-Type` header. GitHub raw rejects that CORS preflight with a 403. Fix: replace `model.api._request` on the model instance so GET requests send no header.
- **NAICS filter:** `NaicsMap.of()` matches the model's `sectorschema` to a crosswalk column. State models report `BEA_2012_Summary_Code`, which matches no column, so the filter leaves no sectors. Fix: `model.info()` reports `BEA_Summary` for state models.
- **Default indicators:** the mosaic's built-in list misses HCAN, HNCN, NNRG, RNRG and CCDD. Fix: pass `view_indicators` with every code in the loaded model, 23 or 16.
- **Stale widgets:** each `applyIO()` call creates a new `urlConfig`. The old one keeps updating its widgets on every hash change, so a national widget could redraw over a state one. Fix: empty the previous config's widget list.
- **React error #300 on national to state:** the new widgets rendered into the containers the prior model's widgets used, so React reconciled them with the old components. Fix: each call renders into new views inside `#iogrid` and `#sector-list` (`newWidgetView()`), and `#sectorListTitles` is placed in each new mosaic view.
- **Full-width impact bars in the inflow-outflow grid (state models):** the grid's multi-regional branch adds D into its A matrix instead of `directImpacts`, so each bar's share is 0/0. Fix: `fixIoGridForStateModel()` rebuilds both after the grid initializes, with buyers from the state's sectors and suppliers from the state and the rest of the US.

## State energy view (`set=energy` with a state)

Hidden:
- `#iogridHolder` (inflow-outflow grid)
- `#indicators` dropdown

Impact Levels (`#impact`, the heatmap mosaic) stays, with the state model's 16 indicators.

The bubble chart already hides for states.

Shown in `#stateEnergy`:
- **Summary cards:**
  - net generation;
  - nameplate capacity;
  - CO2e emissions;
  - CO2e output rate compared with the US;
  - renewables share.
- **Resource mix:** a stacked bar of the state's generation by fuel, with the US mix below it.
- **Subregions table** (Tabulator): the eGRID subregions serving the state, with:
  - share of state generation;
  - 2024 and 2023 CO2e rates and their change;
  - renewables share.

  A checkbox shows all 27 subregions.

On mobile:
- the cards wrap to two columns;
- the legend wraps;
- the table freezes the Subregion column and hides lower priority columns.

Several states (`state=GA,AL`):
- the summary cards total the states (rates and percentages weighted by generation);
- the resource mix shows a bar per state, which opens that state alone, then the US;
- the rates list each state, the states combined, and their subregions by share of combined generation;
- the table adds a States column, naming which of the states have plants in each subregion.

## All-states energy view (`set=energy` with no state)

The USEEIO national charts stay visible. `#stateEnergy` adds:
- **Summary cards** for the US, including the largest source.
- **Resource mix by state:** the US bar, then one compact bar per state from the lowest CO2e rate to the highest. Choosing a state's bar opens its view.
- **CO2e rates** for the US and all 27 eGRID subregions.
- **States table** (Tabulator):
  - generation;
  - CO2e rate;
  - renewables share;
  - largest source;
  - CO2e emissions;
  - capacity.

  Clicking a row opens that state's view.
